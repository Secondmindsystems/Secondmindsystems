- A proposed change can be checked against explicit policy before it is accepted.
- A blocked change can be repaired and evaluated again.
- Decisions and replay results are preserved as inspectable receipts.

### Claim ceiling

The public repositories demonstrate bounded prototypes, documented methods, and reproduced local results. They do not establish cryptographic security, production deployment, universal agent conformance, compliance certification, or access to private Second Mind runtime machinery. Independent separate-machine reproduction remains an open evidence objective.
